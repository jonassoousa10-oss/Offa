# Cerco das Tropas 3D — Protótipo v0.2

Uma implementação original de ação e estratégia de multidões em WebGL/Three.js encapsulado no WebView Android, com cinco fases, personagens 3D arredondados com animação de pernas e braços via renderização instanciada, cenários estilizados, canhão, multidões, portais multiplicadores, torres, chefões e combate.
Não utiliza modelos, sons nem outros recursos proprietários retirados do APK de Mob Control.
A dependência Three.js v0.128 (licença MIT) é incorporada diretamente no APK durante a compilação, portanto o aplicativo roda offline.
Compilação Android no GitHub Actions: artifact expira em 1 dia, sem release permanente. Protótipo não testado ainda em Android real.
