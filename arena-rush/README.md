# ARENA RUSH 3D — protótipo original
Jogo Android nativo experimental em Java / OpenGL ES 2.0, com 5 estágios, personagens low-poly 3D animados, tropas azuis e vermelhas, multiplicadores, torres inimigas, tiros e efeitos sonoros sintetizados localmente.
**Não utiliza nenhum asset, áudio ou código extraído de Mob Control.** O APK fornecido pelo usuário foi analisado apenas para entender o tipo de tecnologia (Unity IL2CPP) e a categoria do jogo. A qualidade não é equivalente à de um jogo comercial com equipe de arte.
Controle: mantenha o dedo na tela e arraste horizontalmente para mirar/disparar. Atravesse portais e destrua a base vermelha. Ao vencer, toque para a próxima fase; ao perder, toque para reiniciar.
A compilação ocorre em um runner efêmero do GitHub Actions. O artifact configurado expira em **1 dia**, mas enquanto existir conta temporariamente na cota de armazenamento do GitHub; ele **não é um APK virtual**.
